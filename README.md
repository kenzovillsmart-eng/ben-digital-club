# BenDigitalClub

Monorepo scaffold for the BenDigitalClub site. Port of 1-website-index.html into a Next.js app and shared UI package.

Getting started

1. Install dependencies: pnpm install
2. Start development: pnpm dev

Structure
- apps/www — Next.js app (app router)
- packages/ui — shared React components
- packages/design-system — design tokens
